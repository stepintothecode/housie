Housie Bingo Caller: No Ads

Tap once, get a number. The board shows what has gone, the voice reads it out, and nobody has to keep track of anything.

Get it on Google Play Source on GitHub

No ads. No tracking. No account. No paid version.

It has no internet permission at all, which is a stronger promise than a privacy policy. Read the policy anyway.

What it does

  • Draws 1 to 90 for Housie and Tambola, or 1 to 75 for Bingo
  • Never repeats a number
  • Reads each number out loud, in English or Hindi
  • Shows the whole board, so players can check without stopping the game
  • Keeps the calls in order, and undoes the last one
  • Holds the screen awake while a game is running
  • Remembers the game if the app closes

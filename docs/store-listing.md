# Store listing

Copy for both stores, kept here so a change is reviewed like any other change.
Character counts are the store limits, not suggestions.

## Google Play

### Title (30 max)

```
Housie Bingo Caller: No Ads
```

27 characters. `housie`, `bingo caller` and `no ads` are all search terms, and
the title is the strongest ranking signal Play gives you.

`no ads` earns its place twice over. People genuinely search it in this
category, and every competing caller is ad-supported, so it is the one line
that separates this listing from the rest of the results page.

The trade-off: `tambola` no longer fits in the title and moves to the short
description, which still ranks, just less strongly. Thirty characters will not
hold housie, bingo, caller, tambola and no ads at once, and `no ads` converts
better than `tambola` ranks.

### Short description (80 max)

```
Tambola, Housie and Bingo number caller. No ads, no tracking, works offline.
```

76 characters. This is where `tambola` gets picked up, and it is the second
strongest signal after the title.

### Full description (4000 max)

```
A number caller for Housie, Tambola and Bingo. Tap once, get a number, and
everyone can see what has already come up.

No ads. No sign-up. No internet needed. Nothing is collected about you.

NO ADS, AND THAT IS NOT A TRIAL

There is no advert anywhere in this app, no video to sit through between
numbers, and no paid tier that removes them, because there is nothing to
remove. The app is not granted internet access at all, so it could not load an
advert even if it wanted to.

WHAT IT DOES

- Draws numbers 1 to 90 for Housie and Tambola, or 1 to 75 for Bingo
- Never repeats a number, so there is nothing to keep track of
- Calls each number out loud, in English or Hindi
- Shows the full board, so players can check a number without stopping the game
- Keeps a running list of calls in order
- Undo, in case you tapped twice
- Keeps the screen awake while a game is running
- Remembers the game if you close the app or your phone dies

BUILT FOR A REAL GAME

The number fills the screen so a room can read it from the back. The board is
right there when someone asks whether 47 has gone. The voice means you are not
shouting over a hall for an hour. Nothing interrupts a game, because there is
nothing to interrupt it with.

HOUSIE, TAMBOLA, BINGO

Housie and Tambola both draw 1 to 90. Bingo draws 1 to 75, in five lettered
columns, and the app shows the letter with the number. Switch between them in
settings.

FREE, AND STAYING FREE

There is no paid version and nothing held back behind one. There are no
adverts, no tracking and no account. The app has no internet permission at
all, which is a stronger promise than a privacy policy.

If it is useful to you, there is a link in the app to chip in. It is a tip, not
a purchase, and it unlocks nothing.

Made by Step Into The Code.
```

### Keywords Play indexes from the above

`housie`, `tambola`, `bingo`, `bingo caller`, `housie caller`, `tambola caller`,
`number caller`, `random number`, `90 ball`, `75 ball`, `offline`, `no ads`,
`ad free`, `bingo without ads`, `housie board`, `number generator`, `party game`

Play has no keyword field. It reads the title, short description and full
description, so those terms appear naturally above rather than in a list.

### Category and tags

- Category: **Games > Casual** (not Apps > Entertainment; a caller is a game
  tool and casual is where people browse for it)
- Tags: Casual, Board, Family
- Content rating: expect **Everyone / 3+**. There is no gambling here: the app
  draws numbers and never handles a stake, a score or a prize. Answer the
  IARC questionnaire literally and it lands at 3+.

### Data safety form

Answer **no data collected** and **no data shared**. That is literally true:
there is no analytics, no crash reporting, no adverts and no `INTERNET`
permission in the manifest. Tick "data is encrypted in transit" as not
applicable.

## App Store

### App name (30 max)

```
Housie Bingo Caller: No Ads
```

27 characters. Same as Play, so the two listings are one product.

### Subtitle (30 max)

```
Tambola caller, works offline
```

29 characters. Apple indexes the subtitle separately from the name, so this is
where `tambola` and `offline` get picked up.

### Keywords field (100 max, comma separated, no spaces)

```
tambola,housie,bingo,caller,number,draw,random,party,board,90,75,adfree,free
```

76 characters. Do not repeat words already in the name or subtitle; Apple
indexes those separately and a repeat wastes the field, which is why `no`,
`ads` and `offline` are absent here.

### Promotional text (170 max)

```
Tap once for the next number. Full board, called list, and a voice that reads
each number in English or Hindi. No ads, no tracking, works offline.
```

### Category

Primary **Games > Board**, secondary **Games > Family**.

### Age rating

4+. No gambling, no user content, no links to social networks. The support
link opens a web page, which Apple treats as an external link, not a purchase.

## Screenshots

Eight per store. Shoot on a 6.7 inch phone frame; both stores scale down from
the largest size.

Lead with portrait, since that is how the store previews them, but add one or
two landscape shots at the end. The app rotates, and a sideways board with the
controls to the right is worth showing to anyone who props a phone on a table.

1. Game screen mid-game, dark, a big number showing, board half filled
2. Same shot in light mode
3. Board close-up with a caption about checking a number without stopping
4. Bingo 1-75 mode, so the listing shows both games
5. Settings, showing the Hindi voice option
6. The history strip and undo, captioned for the "did I tap twice" case
7. A completed game
8. The about page, captioned "No ads. No tracking. No account."

Caption each one. A screenshot with no caption is a wasted slot: most people
never scroll past the third image, so put ad-free, offline and Hindi in the
first three.
